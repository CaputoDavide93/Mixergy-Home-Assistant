# Agent instructions

Mixergy is a Home Assistant custom integration (domain `mixergy_tank`) for
Mixergy smart hot water tanks, installed through HACS. It talks to Mixergy's
cloud API; there is no local API.

## Build, test, lint

```bash
make venv       # .venv with the pinned Home Assistant and test plugin (needs uv)
make check      # ruff, mypy (strict), pytest with a 95% coverage floor, both generators with --check
make diagram    # redraw docs/assets/*.svg and the generated entity tables
make screenshots # retake docs/assets/screenshots/ from a throwaway Home Assistant and a demo tank
```

Run `make check` before and after a change; anything green stays green.

## Layout

- `custom_components/mixergy_tank/`: the integration. `api.py` is the cloud client,
  `coordinator.py` polls, one module per platform (`sensor.py`, `switch.py`, ...),
  `config_flow.py`, `diagnostics.py`, `device_trigger.py`, `services.yaml`,
  `strings.json` and `translations/` (en, de, fr, it), `brand/` for the icons.
- `tests/`: pytest suite; `tests/test_repository_hygiene.py` guards the repo layout.
- `tools/`: `gen_diagram.py`, `gen_entity_docs.py`, and `screenshots/` (demo data only,
  serial `A12345`, nothing sent to Mixergy).
- `docs/`: start at `docs/README.md`. `docs/entities.md` and the diagrams are
  generated: never edit them by hand. `llms.txt` is kept in step with the docs.

## Do not change

- The domain `mixergy_tank`, entity ids, unique ids, statistic ids, service names,
  `hacs.json` keys and public URLs. Renaming any of them breaks existing installs.

## Conventions

- Conventional commits (`fix:`, `feat:`, `docs:`, `refactor:`, `ci:`, `chore:`)
  authored by the repo owner. No co-author trailers, session ids or
  "generated by" lines in commits, PRs, issues or comments.
- `main` is protected: branch, pull request, required checks, squash or rebase merge.
- Documentation must be true of the code: no hand-typed counts that can drift.
  User-visible changes get a `CHANGELOG.md` entry under `[Unreleased]`.
- Releases: roll `[Unreleased]` into a version, bump `manifest.json`, tag `vX.Y.Z`,
  `gh release create`.
- Never commit secrets, keys, tokens, IP addresses, private hostnames or personal
  e-mail. The one public contact address is caputodav@gmail.com.
- Keep this repository about Mixergy only: no mentions of other projects.
