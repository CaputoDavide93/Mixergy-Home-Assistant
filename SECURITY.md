# Security Policy

## Supported versions

Security fixes are provided for the latest published Mixergy integration release.
Update through HACS before reporting an issue that is already fixed upstream.

## Reporting a vulnerability

Do not open a public issue for suspected vulnerabilities or include credentials,
tokens, tank serial numbers, or diagnostics in public discussions.

Use GitHub's **Security** tab and select **Report a vulnerability** to open a
private security advisory. Include the affected integration and Home Assistant
versions, impact, reproduction steps, and any suggested mitigation. You should
receive an acknowledgement within seven days.

For ordinary bugs without security impact, use the public bug report template.
